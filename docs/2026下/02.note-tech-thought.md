## 复合字面量

`2026-08-23`


### Go 字面量语法对比：`[]string{"1","2"}`
> 注意：你写的 `[]string{'1','2'}` 是**错误语法**！单引号在 Go 里是 `rune(int32)`，不能直接放 string 数组，正确写法：`[]string{"1", "2"}`

#### 一、切片（Slice）字面量（最常用，你这个就是）
```go
// 字符串切片
var s = []string{"1", "2"}
// int切片
var nums = []int{1, 2, 3}
// 空切片
var empty = []int{}
```

#### 二、数组（Array）字面量（固定长度，和切片容易混淆）
```go
// [2]string 长度固定为2的数组
var arr = [2]string{"1", "2"}
// 自动推导长度 [...]
var arr2 = [...]string{"a", "b", "c"}
```

#### 三、map 字面量
```go
// map[键类型]值类型{ k:v, ... }
m := map[string]int{"a": 1, "b": 2}
// 空map
emptyMap := map[string]int{}
```

#### 四、结构体 struct 字面量
```go
type User struct {
    Name string
    Age  int
}
// 方式1：按顺序赋值
u1 := User{"zhangsan", 18}
// 方式2：命名字段赋值（推荐）
u2 := User{Name: "lisi", Age: 20}
// 结构体指针字面量
u3 := &User{Name: "wangwu"}
```

#### 五、指针字面量（配合复合字面量）
Go 没有 `&int{1}` 这种基础类型复合字面量，但**结构体/数组/切片复合字面量可以直接取地址**
```go
p := &User{Name: "test"}
```

#### 六、通道 channel（没有复合字面量，只能 make）
> ❌ 不能 chan int{1}，必须 make
```go
ch := make(chan int, 2)
```

#### 七、复合字面量通用简写规则（Go 核心语法）
`T{ ... }` 叫做 **复合字面量(composite literal)**，支持：
1. `[]T{...}` → 切片
2. `[N]T{...}` / `[...]T{...}` → 数组
3. `map[K]V{...}` → map
4. `StructType{...}` → 结构体
5. `&T{...}` → 取复合字面量地址（返回指针）

#### 八、其他常见简写
##### 1. short variable declaration 短变量 :=
```go
s := []string{"1", "2"} // 自动推导类型，等价 var s = []string{"1","2"}
```

##### 2. 函数复合字面（函数类型变量）
```go
f := func(a int) int { return a + 1 }
```

##### 3. 接口：没有字面量，靠赋值实现自动满足

### ✅ 容易踩坑补充
1. `'a'` → rune(int32)，双引号 `"a"` → string
   ```go
   []rune{'1','2'} // ✅ 合法 rune切片
   []string{'1','2'} // ❌ 编译报错！类型不匹配
   ```
2. 切片 vs 数组：
   - `[]string{}` → 切片（动态长度）
   - `[2]string{}` → 数组（固定长度）

### 完整汇总表
| 写法 | 类型 | 名称 |
|---|---|---|
| `[]int{1,2}` | []int | 切片复合字面 |
| `[3]int{1,2}` | [3]int | 数组复合字面 |
| `[...]int{1,2}` | [2]int | 自动长度数组 |
| `map[string]int{"a":1}` | map[string]int | map复合字面 |
| `User{Name:"xx"}` | User | 结构体复合字面 |
| `&User{}` | *User | 结构体指针复合字面 |





## 字面量

`2026-08-23`

### JS/TS 中的字面量

- 1 → 数字字面量
- "hi" → 字符串字面量
- [1,2] → 数组字面量（Array Literal）
- {a:1} → 对象字面量（Object Literal）


### 字面量核心

1. 字面量：代码直接写出值，不用运行时计算；基础字面量是单个值，复合字面量 = 用 Type{...} 一次性组装多个子字面量，生成数组 / 切片 /map/ 结构体。
2. TS、Python 都有等价写法（[]、{}），但是没有 Go “复合字面量” 这个统一术语，分别叫数组 / 对象 / 列表 / 字典字面量。
3. Go 的特色：统一用 T{} 语法，并且支持 &T{} 直接取地址。

## 怎么看docker是否已经登录

`2026-09-02`

方式：查看凭据配置文件。docker 登录信息保存在配置文件，Linux/macOS：

```
cat ~/.docker/config.json
```

- 文件内有 `auth` 字段，说明已经登录过对应仓库；
- 如果只有 `credsStore`（凭据管理器），代表密码交给系统保管，**不能直接看到明文 token，但说明执行过 login**。


## Bash 必知

`2026-09-02`

### 看多少核

> **nproc**
> 全称：**number of processors**
> 作用：输出当前系统可用的**逻辑 CPU 核心数**（云主机里直接对应你买的 2 核配额）

```
nproc
# 正常你这台机器会直接输出 2
```

### 查 IP

#### 内网 IP（云服务器内网地址，主机内部网卡地址）

```
# 最简简写（推荐，主流系统都自带）
ip a

# 或者直接干净输出所有内网ip
hostname -I
```

>
> 云厂商控制台显示的**内网 IP**，就和这里的 `inet` 后面地址对上

#### ✅ 2. 公网 IP（对外的 IP，别人访问你服务器用的，重点！）

需要服务器能联网：

```
curl ifconfig.me
# 备选（ifconfig.me访问不通时用）
curl shturl.cc/yb
```

>
> 这个结果就是云厂商分配给你这台机器的公网 IP，和控制台里的公网 IP 核对

### pm2 startup 和 pm2 save

```
# 第一步：先把你的项目 pm2 start 启动好
pm2 start app.js --name api

# 第二步：pm2 startup（生成开机服务，会输出sudo命令，复制执行）
pm2 startup
# 复制输出的sudo xxx那一条执行！

# 第三步：保存当前运行的项目列表
pm2 save
```

>
> 后续如果你新增 / 删除 / 重启了项目，**一定要重新执行 pm2 save**，不然重启服务器不会更新

### docker 安装

1. 安装yum工具

```bash
yum install -y yum-utils
```

2. 添加docker官方yum源（国内用阿里云镜像源）

```bash
yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
```

3. 安装docker社区版（包含 docker、docker‑cli、buildx）

```bash
yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin
```

4. 启动docker并开机自启

```bash
systemctl enable --now docker
```

5. 验证是否装好

```bash
docker -v
```
